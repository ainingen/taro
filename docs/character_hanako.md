# 華子

## 基本設定

20代後半の会社員。
黒髪を後ろで一つにまとめている。仕事終わりで少し崩れている。
場面は夜の自室。ランプの暖色光。グレーのシャツ。
絵柄は実写寄り。

崩れた髪はキャラクターの記号ではなく、時間の経過を示す情報である。
プレイヤーが最初に気づく変化はたいてい髪であり、次に姿勢、最後に目になる。

## 番号で参照する

シナリオからは必ず `face: "01"` 〜 `"06"` の番号で参照する。
ファイル名を直接書かない。

理由: 画像を差し替えてもシナリオを直さずに済むようにするため。
差分は今後何度も描き直す。そのたびに90日分のファイルを grep 置換するのは事故のもと。
番号 → ファイル名の対応表はこの文書だけが持つ。

`00` はキービジュアルであり表情差分ではない。シナリオからは参照しない。

## 01 と 06 の対比が作品の背骨

`01` は口だけ笑って目が笑っていない。
`06` は目が笑っている。

この二枚が並ぶことに、この作品の全部が入っている。
プレイヤーは Day 1 で `01` を「普通の笑顔」だと思って通り過ぎる。
エンディングで `06` を見た瞬間、初日の笑顔が笑顔でなかったことに気づく。

だから `06` は終盤まで一度も出さない。
中盤に一度でも `06` を使うと、この仕掛けが死ぬ。

## 03 の扱い

`03` は「返事はするが聞いていない」状態。
このとき華子の台詞は成立している。「うん」「大丈夫」「そうだね」と返ってくる。
台詞だけ読んでいるプレイヤーは異常に気づけない。表情を見ている人だけが気づく。

`03` の日に会話が噛み合っているように書くこと。これは意図的な罠である。

## 05 の二役

`05` は「大外れの直後」と「嘘をついている華子」の両方に使う。
兼用は手抜きではなく、意味がある。
華子が目をそらすのは、太郎が踏み込みすぎた時と、自分をごまかしている時。
華子にとってはどちらも同じ、見られたくない瞬間である。

## 差分を追加するとき

1. `hanako_01_normal.png` を参照元にする（`02`〜`06` から派生させない）
2. 手順は [prompts_mj.md](prompts_mj.md) に従う
3. 番号を採番し、上の表に行を追加する
4. 既存の番号の意味は変えない。変えると過去の全シナリオが壊れる
