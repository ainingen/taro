# 癒しマン太郎 (taro)

ブラック企業で孤独死した主人公・太郎が、会社員の華子のPCに宿る。
太郎は「癒しマン」として、観察と質問で華子を癒す。全90日。

## この作品の芯

太郎はPCが見えるものしか見えない。
これは演出の都合ではなく、そのままUIの制約になっている。
カメラがONなら顔が見える。OFFならテキストしか届かない。
プレイヤーが持てる情報の量が、そのままゲームの手触りを決める。

華子の本当の問題は病名ではない。
「異常な状態を正常だと思っていること」が問題である。
そして太郎自身も同じ価値観で死んだ人間なので、序盤は華子に共感してしまう。
神様が「お前、それで死んだんじゃが」と指摘する日が、太郎の転換点になる。

ラスボスは人ではなく、「限界まで頑張ることが偉い」という価値観そのもの。

## モード

| モード | カメラ | プレイヤーがすること | ゲーム性 |
|---|---|---|---|
| 華子編 | ON | 表情・姿勢・帰宅時間・検索履歴を読む | 観察 |
| 出張編 | OFF | 限られた質問枠で相手の状況を引き出す | 傾聴 |
| 癒しマンONLINE | OFF | 出張編と同じUIのエンドレスモード | クリア後 |

出張編で相手は太郎を「AI相談窓口」だと思っている。太郎の正体を知らない。

## エンディング

華子が転職して笑顔を取り戻し、太郎が成仏する。
数年後、太郎は華子の子として生まれ変わり、
将来ネット相談サービス『癒しマン』を始めるところまでを描く。
